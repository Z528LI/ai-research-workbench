Method and CSV format

Use a CSV with one row per ticker and date and the columns date,symbol,close. Choose a benchmark from the tickers in the file. Use a consistent closing-price series for each symbol, preferably adjusted for splits and dividends. The sample contains synthetic tickers and prices.

Returns compare the first and last dates a stock shares with the benchmark. The chart compares dates common to every selected series. Daily returns use adjacent observed benchmark dates when a stock has both prices. The calculation skips intervals with an unavailable stock close.

Beta is the slope of stock returns on benchmark returns. The displayed 95% interval uses Bartlett-weighted Newey–West standard errors. Beta requires 20 paired returns and variation in benchmark returns. Capture divides the stock’s mean return by the benchmark’s mean return for the selected direction and requires five observations in that direction.

Breadth counts eligible non-benchmark tickers in the supplied file. The 20-session average includes the last available session. This tool measures historical behavior for research.
